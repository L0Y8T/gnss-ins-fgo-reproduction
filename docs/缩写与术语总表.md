## 1. 最基础的 5 个（必须背下来）

这 5 个缩写构成了整个研究的骨架，读任何一篇 GNSS/INS 论文都会用到。

缩写 英文全称 中文 一句话理解

GNSS Global Navigation Satellite System 全球导航卫星系统 用天上的卫星来定位。是总称，包含 GPS、北斗、Galileo、GLONASS
INS Inertial Navigation System 惯性导航系统 靠加速度计+陀螺仪自己推算位置的系统。不怕遮挡，但误差会累积
IMU Inertial Measurement Unit 惯性测量单元 INS 的硬件本体（那坨传感器）。IMU 是硬件，INS 是系统
EKF Extended Kalman Filter 扩展卡尔曼滤波 经典卡尔曼滤波的非线性版本。边走边算，每来一个测量就更新一次
FGO Factor Graph Optimization 因子图优化 把所有测量画成一张「关系图」，然后一起优化求最优解

这五者的关系（一句话）：

GNSS 和 INS（靠 IMU 测数据）是两种互补的定位手段；要把它们合起来用，有两种主流算法——老的叫 EKF，新的叫 FGO。这篇论文就是在比较这两种算法。

## 2. 核心论文术语（Wen 2021 用得最多的）

缩写 英文全称 中文 说明

GNSS-INS GNSS/INS integration GNSS/INS 组合导航 把两者融合。这是本文的研究对象
LC Loosely Coupled 松耦合 用接收机算好的位置做融合。简单，但信息有损失
TC Tightly Coupled 紧耦合 用卫星原始伪距做融合。复杂，但信息更多
UTC Ultra-Tightly Coupled 超紧耦合 连接收机基带相关器都用上。需要改接收机固件，本文不涉及
MAP Maximum A Posteriori 最大后验估计 在所有可能答案里，选「看到数据后概率最大」的那个。FGO 的数学出发点
MM Motion Model 运动模型 本文指「恒速模型」因子：位置 = 上一位置 + 速度×Δt
SLAM Simultaneous Localization and Mapping 同步定位与建图 机器人边定位边画地图。因子图优化最早大规模应用的领域
CRT Contemplative Real-Time 沉思实时（方法名） Zhao 等人提出的一种滑动窗口批优化方法。本质与 FGO 相同，只是换了名字
MSCKF Multi-State Constraint Kalman Filter 多状态约束卡尔曼滤波 视觉惯性导航里的经典算法，用零空间矩阵压缩状态

## 3. 卫星导航（GNSS）专用术语

缩写 英文全称 中文 说明

GPS Global Positioning System 全球定位系统 美国的系统。最常被当成 GNSS 的代名词，但严格说只是其中一个
BDS / BeiDou BeiDou Navigation Satellite System 北斗卫星导航系统 中国的系统。本文用了 GPS + 北斗
GLONASS Globalnaya Navigazionnaya Sputnikovaya Sistema 格洛纳斯 俄罗斯的系统
Galileo — 伽利略 欧盟的系统
QZSS Quasi-Zenith Satellite System 准天顶卫星系统 日本的区域系统
LOS Line-of-Sight 视距 接收机能直接看到卫星（信号没被挡）。这种测量可信
NLOS Non-Line-of-Sight 非视距 卫星被建筑挡住了，只收到反射信号。误差可达 30–40 米，城市定位的头号杀手
multipath — 多路径 信号经过建筑反射后到达，走了更长的路 → 测出来的距离偏大
UERE User-Equivalent Range Error 用户等效测距误差 把所有测距误差源折算成一个距离误差量。本文取 10 m
PDOP Position Dilution of Precision 位置精度因子 只由卫星几何分布决定的误差放大倍数。卫星挤一起 → PDOP 大 → 定位差
DOP Dilution of Precision 精度因子 PDOP 的统称。还有 HDOP（水平）、VDOP（高程）
SNR / C/N₀ Signal-to-Noise Ratio / Carrier-to-Noise density 信噪比 / 载噪比 信号强度与噪声之比。SNR 低 → 测量不可信
elevation angle — 仰角 卫星相对地平线的高度角。仰角低 → 信号穿更厚大气 → 更不可信
pseudorange — 伪距 信号飞行时间 × 光速。因为接收机钟不准，不是真距离，所以叫「伪」
carrier phase — 载波相位 卫星载波的相位，精度可达厘米级。本文没用（只用伪距）
RTK Real-Time Kinematic 实时动态差分 用载波相位做差分，可达厘米级
PPP Precise Point Positioning 精密单点定位 用精密星历和钟差做单机高精度定位
DGNSS Differential GNSS 差分 GNSS 用地面基准站发改正数，消掉公共误差
RINEX Receiver Independent Exchange Format 与接收机无关的交换格式 GNSS 原始观测的标准文本格式。UrbanNav 就提供这个
NMEA National Marine Electronics Association （格式名） 接收机输出的标准语句格式，人可读但精度低
PPS Pulse Per Second 秒脉冲 每秒一个电脉冲，用于硬件级时间同步
基带 / baseband — 基带 接收机内部处理原始信号的电路部分。改它才能做超紧耦合

## 4. 状态估计与优化术语（FGO/EKF 的核心）

缩写 英文全称 中文 说明

KF Kalman Filter 卡尔曼滤波 1960 年提出的递归最小方差估计器。EKF 是它的非线性版
UKF Unscented Kalman Filter 无迹卡尔曼滤波 不做线性化，用「sigma 点」传播分布
IKF / IEKF Iterated (Extended) Kalman Filter 迭代（扩展）卡尔曼滤波 更新步做多轮迭代的 EKF
GN Gauss-Newton 高斯-牛顿法 求解非线性最小二乘最常用的迭代算法。FGO 用它求解
LM Levenberg-Marquardt 列文伯格-马夸尔特法 GN + 阻尼，比纯 GN 更稳。Wen 2021 用的是它
iSAM Incremental Smoothing and Mapping 增量平滑与建图 用贝叶斯树做增量求解，让 FGO 能实时跑。4.5 节的方法
Jacobian — 雅可比矩阵 函数的导数矩阵，用在线性化步骤
Covariance — 协方差 描述不确定度的矩阵。它决定了每个测量的「话语权」
BT Bayes Tree 贝叶斯树 iSAM 用的数据结构
fixed-lag Fixed-Lag Smoothing 固定滞后平滑 窗口固定为最近 N 个历元，但允许反复重优化
ablation study — 消融实验 故意去掉某部分，以考察它的作用。本文 4.3 节就是

## 5. 误差与噪声建模术语

缩写 英文全称 中文 说明

GMM Gaussian Mixture Model 高斯混合模型 用若干高斯分布的加权和拟合任意形状的分布。论文 4.4 节的核心工具
EM Expectation-Maximization 期望最大化 拟合 GMM 的标准算法（Pfeifer 的工作用的）
RMS Root Mean Square 均方根 √(误差平方的平均)。比「平均误差」更严厉（会放大大的误差）
RMSE Root Mean Square Error 均方根误差 同 RMS，强调是误差
std Standard Deviation 标准差 描述误差的波动程度
P95 95th Percentile 95 百分位 95% 的误差小于这个值。比均值更能反映「最差情况」
CEP Circular Error Probable 圆概率误差 50% 的点落在这个半径内
2D / 3D 2-Dimensional / 3-Dimensional 二维 / 三维 本文只评估 2D 水平（东、北方向）
outlier — 异常值 明显偏离正常范围的测量。城市里被 NLOS 拉偏的伪距就是
OU process Ornstein-Uhlenbeck process 奥恩斯坦-乌伦贝克过程 带回归项的随机游走。仿真里用它生成加速度
whitening — 白化 把残差和雅可比行按 √权重 缩放后再求解。省内存，也是 Σ 非对角时的通用写法；它不改变条件数
burn-in — 预热期 丢掉滤波器还没收敛的前几个历元再统计

## 6. 本复现项目里的代号

### 6.1 希腊字母与数学符号（ 最容易混，重点看）

符号 读法 中文 在本文档里的含义

σ (sigma) 西格玛 标准差 一般指某个测量的噪声标准差。下标区分是哪一个（见下）
Σ (Sigma 大写) 西格玛 协方差矩阵 注意：小写 σ 是「标准差」（一个数），大写 Σ 是「协方差矩阵」（一个矩阵）！两者完全不同
σ_p — 位置标准差 代码里的 `mm_position_sigma` = 0.60 m（运动模型因子的假定 σ；真值上实测残差只有 0.085 m）
σ_v — 速度标准差 代码里的 `imu_velocity_sigma`（IMU 因子的速度增量残差），默认 0.70 m/s
ρ (rho) 柔 相关系数 代码里的 `accel_rho` = 0.50（加速度的时间相关性，越接近 1 越平滑）
Δ (Delta) 德尔塔 增量 Δt = 时间间隔
Δt — 时间步长 两个历元之间的时间差，1 Hz 时 = 1 秒
λ (lambda) 兰姆达 波长 / 经度 附录 A 里指经度
φ (phi) 斐 纬度 附录 A 里指纬度（原文误印成 ∅，见《论文讲解_对照复现版.md》的说明）
θ (theta) 西塔 角度 一般指姿态角
ζ (zeta) 泽塔 — 论文式 (18) 里的因子函数符号
x̂ x-hat x 的估计值 帽子 ^ 表示「估计值」
X* — 最优解 星号 * 表示「最优/最终结果」
^T transpose 转置 把列向量写成横排

 最需要小心的一对：`σ`（标准差，标量）与 `Σ`（协方差矩阵）。论文式 (9)(16)(22)(27) 里的 `Σ` 都是协方差矩阵；而说「σ_v 从 0.70 降到 0.15」说的是标量标准差。

## 7. 五组容易混淆的缩写（重点）

### 7.1 `LC` / `TC` / `UTC` —— 三种耦合方式

 用什么数据 难点 本文涉及

LC 松耦合 接收机算好的位置 只有位置，丢了卫星级信息
TC 紧耦合 卫星原始伪距 每颗卫星一个方程，计算量大
UTC 超紧耦合 接收机基带相关器输出 要改接收机固件

记忆法：「松」→ 松手，让接收机自己算；「紧」→ 抓紧原始数据不放。

### 7.2 `EKF` / `UKF` / `IKF` / `MSCKF` —— 各种卡尔曼

 全称 特点

KF Kalman Filter 线性系统 + 高斯噪声，最优解
EKF Extended KF 一次线性化近似非线性 → 本文的对比基准
UKF Unscented KF 不做线性化，用 sigma 点传播
IKF Iterated EKF 多轮迭代的 EKF
MSCKF Multi-State Constraint KF 视觉惯性专用，用零空间压缩状态

### 7.3 `GNSS` / `GPS` / `BDS` —— 总称与具体系统

- GNSS 是总称（所有卫星导航系统的集合）；
- GPS 是美国的一个系统；
- BDS（北斗） 是中国的一个系统。

日常口语里常把 GPS 当 GNSS 用，但写论文时必须区分——本文用的是 GPS + 北斗（BDS）。

### 7.4 `σ` vs `Σ` vs `ρ` —— 三个长得像的符号

符号 类型 含义

σ（小写 sigma） 标量 标准差（一个数），如 σ_v = 0.70 m/s
Σ（大写 sigma） 矩阵 协方差矩阵，如式 (22) 的 Σ^MM
ρ（rho） 标量 相关系数，如 accel_rho = 0.50

### 7.5 `LOS` / `NLOS` / `multipath` —— 三种信号接收状态

 全称 状态 后果

LOS Line-of-Sight 卫星可见 测量可信
NLOS Non-Line-of-Sight 卫星被挡住，只收到反射信号 误差可达 30–40 米
multipath — 直射+反射信号混在一起 误差几米
